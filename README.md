# blendthink.github.io

An interactive portfolio built with Dart and [Jaspr](https://jaspr.site/).

Visitors explore an engineer's room, move a small character, inspect objects,
and discover works, interests, and hidden features.

## Setup

The Dart SDK is managed with [mise](https://mise.jdx.dev/).

```sh
mise install
mise run get
```

## Development

```sh
mise run serve
```

The development server is available at <http://localhost:8080>.

## Verification

```sh
mise run check
mise run build
```
